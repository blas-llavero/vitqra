# Measured algorithm comparison — v0.5.4 initial development

The first executable optimization step compares a naive left-to-right motif search with Knuth-Morris-Pratt (KMP) for the curated Rosalind SUBS educational problem. Both are fixed C# algorithms, not code generated by a model. The existing solver and its original sample checkpoint are unchanged. Other challenges retain their existing behavior. No new provider calls, permissions, external dependency or clinical functionality.

After the official public sample matches, the queue evaluates both alternatives against that sample and a deterministic synthetic suite: seven explicit cases (including overlapping matches, absent motifs and long repeated prefixes) plus 64 seeded generated cases. The generated cases use an independent ordinal substring-search reference. All outputs must agree with the reference. Counts are literal character comparisons; KMP includes prefix preprocessing. The selected candidate minimizes aggregate comparisons over the 71 synthetic cases, with ties going to naive. The public sample counts are reported separately. No elapsed time, memory use, unseen competition score or cross-task ranking is inferred. The suite is fixed and is not an independent held-out scientific benchmark. The selected candidate is a recommendation in the report, not a replacement for the previously checked solver. No AI-generated code is executed and no iterative arbitrary experiment runner is enabled.

A deterministic local checkpoint motif-benchmark-v1.txt contains the protocol, seed, source and sample hashes, synthetic case count, comparison totals, sample comparisons and selected candidate. It is written only after verified public evidence and sample checks; it is regenerated and compared before use. Modified existing records are preserved, not overwritten. Missing or mismatched records are omitted from the report rather than fabricated. Report viewer and generated PDF/ZIP include the measurement separately from unvalidated AI proposals. The original documentary report stays unchanged, so prior report verification is preserved. Technical keys are invariant English; section heading and interpretation are localized in ten languages. Existing storage, research and privacy gates remain. The benchmark uses bounded input and a fixed number of cases; it currently runs synchronously, so measure frame time on Quest.

Future work: integrate model-proposed candidate selection within a reviewed algorithm registry, expand to other tasks, support official scoring metrics and independent datasets, execute isolated reviewed experiments, measure resources and uncertainty, iterate under explicit budgets, and record failures. This milestone does not establish a competition win, general AI optimization, clinical benefit or scientific validity.
