# AI-guided motif revision — v0.5.4a development

The existing two-call educational drafting pipeline now asks each configured provider (local llama.cpp, ChatGPT plan connector, or reviewed private Ollama) to choose one of two fixed executable algorithms for the Rosalind SUBS task. First response: exact first-line CANDIDATE=NAIVE or CANDIDATE=KMP plus explanation. Second response: critique and revise the selection using measured aggregate character comparison counts from the fixed 71-case synthetic suite, including preprocessing. The same two calls and existing provider gates are used; no extra inference allowance, automatic fallback or new endpoint. The local motif prompt uses an authored abstract task instead of a downloaded page excerpt. The external connector sends only the authored educational task, language, two bounded synthetic totals and previous model output, not downloaded sequences, user input, notes or patient data. Other tasks remain unchanged. No generated code, command, tool or arbitrary algorithm is executed.

After drafting, the report reconstruction evaluates both reviewed algorithms on a separate fixed 48-case synthetic suite with a distinct seed and workload, never included in the prompts. Both must match the ordinal-search reference. The report compares the initial and revised model choices on this suite and records improved, regressed, unchanged or unavailable. It independently selects the lower measured comparison count (ties favor NAIVE) even if the AI chooses poorly. An invalid candidate line does not become executable or count as a valid revision. The choice is a report recommendation, not an automatic replacement of the original solver. This is one feedback/revision cycle, not an unlimited iterative optimizer. The fixed held-back suite is public source code and not an independent competition or scientific benchmark; the model could have prior knowledge. No claims about execution time, memory, clinical benefit or winning a challenge.

A new optional protocol identifier is included in the existing draft digest for newly generated motif drafts only. Legacy drafts keep their original digest and are not retroactively labeled as revised. Existing records are not overwritten; a previously saved draft will not automatically gain this feature. In the viewer and generated PDF/ZIP, optimization details are added only when a verified original sample benchmark and a matching verified protocol draft are available. Counts are recomputed; the record includes the draft digest. Original evidence, reports and prior package revisions remain unchanged. Technical keys are invariant English; localized heading and interpretation in ten languages. The general scientific and clinical release gates remain closed.
