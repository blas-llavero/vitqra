# Ollama integration — v0.5.3d development

The initial XR AI Settings panel now offers Ollama alongside Local AI and ChatGPT. The provider preference persists; no provider switch occurs automatically. Selecting Ollama opens a subpanel with configured server, catalog status, selected model, automatic/manual cycle and manual refresh. The existing ChatGPT card and layout are preserved. A configured catalog is queried once on workspace startup even when another provider is selected. No account, model download or inference test occurs during startup.

## Provisioning and trust boundary

On a user-controlled computer install a reviewed Ollama version from its official source, audit its license and dependencies, and review each intended model's license, provenance, capabilities and resource needs. Set OLLAMA_NO_CLOUD=1 and restart; verify the cloud-disabled log. Restrict outbound server traffic to prevent cloud fallback. Keep the native HTTP endpoint bound to loopback and use a reviewed HTTPS reverse proxy restricted by firewall/VPN to the intended headset. Do not expose an unauthenticated Ollama port to the Internet. The proxy must present a certificate trusted by Android/Unity with the configured private IPv4 address in its SAN. No certificate validation bypass is implemented. This version accepts only canonical HTTPS RFC1918 IPv4 origins with optional port and no path, credentials, query or fragment. It intentionally does not discover LAN hosts or accept public/cloud endpoints. Client-side checks cannot prove server ownership, its cloud setting, or the proxy's behavior; the operator must enforce these independently. The server may log requests.

In Unity, set the workspace Inspector fields ollamaServer, allowOwnedOllamaServer (explicit operator authorization) and ollamaReviewedModels. The array contains reviewed exact installed names and 64-character lowercase manifest digests in descending research preference. Leave authorization false until the server and model review are complete. No real server or model digest is embedded in the repository. Runtime server editing, credentialed proxy support, certificate provisioning and a dynamic external capability source are not implemented. The headset subpanel shows the provisioned configuration and can refresh the catalog and select among eligible models. The manual model choice is session-only.

GET /api/tags returns installed metadata, not all downloadable models. The adapter bounds the JSON response and excludes duplicate names, malformed digests, nonlocal metadata and cloud-looking names; only exact reviewed name/digest pairs are eligible. Automatic mode selects the highest reviewed preference actually present in the refreshed inventory. Parameter count and date are not treated as quality scores. A changed digest requires review, not silent approval. A failed catalog is cleared; an unavailable manual model is not silently replaced. No comparative benchmark or universal provider ranking is claimed. Automatic inventory refresh does not automatically expand the approved digest list.

## Educational inference

When Ollama is selected and a reviewed model is available, the existing evidence queue can process only the same five public educational tasks supported by the ChatGPT prototype. No source HTML, actual sequence, user query, private note, patient record or conversation is sent. It uses authored task descriptions and two bounded calls to /api/chat, with no tools and stream=false. The second call critiques the first and requests human-impact and uncertainty assessment. Requests require a complete stop response with the expected model name; returned text is limited to 6000 UTF-16 characters per pass. Name and digest are refreshed before each request and after the second response. The manifest digest is server metadata, not independent weight verification, and server changes between check and execution cannot be excluded. No code execution, model installation, automatic submission or clinical recommendation is enabled. Model output remains unvalidated. Cancellation aborts the current client request; remote computation may continue. Failed drafts pause the existing queue. No paid provider fallback. The local server has its own resource costs and existing 12-job session ceiling; ChatGPT's separate plan counter is not used.

Ollama drafts use a separate private directory, retaining the model name, reported manifest digest and local evidence digest. Existing drafts are not overwritten on model change. The report viewer and PDF/ZIP inherit the provider-specific identity. The broader scientific gate is unchanged. Conversation integration, translation, competitive experiments, general evidence analysis and community release remain pending.
