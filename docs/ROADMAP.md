# Roadmap

**Current gate:** retain Unity/OpenXR as selected by the author; continue v0.3.3 with local speech integration, opt-in persistent chat and window resizing. The local-only settings guard, opt-in single-conversation persistence and optional microphone/transcription bridge are implemented in source. Sherpa-ONNX STT/TTS source adapters are added in v0.3.4; native compilation, model provisioning, device validation, multiple conversations and cross-session window layout persistence remain pending. Independent resizing source is added in v0.3.5; editor and headset tests remain pending. No Godot migration is planned. See [OPEN_SOURCE_POLICY.md](OPEN_SOURCE_POLICY.md).

1. Source overlay, desktop preview, README, settings and notes (this package).
2. Unity XR rig and passthrough via the Mixed Reality template; repositionable world-space panels and controller input source added in v0.2.0. Editor import, template configuration and physical Quest 3 tests remain pending.
3. v0.3.5: independent proportional resizing and reset controls with half-second edge hover activation and automatic hiding; v0.3.4 localization update: device-controlled localization and English repository baseline; v0.3.4: local neural speech source adapters and optional playback; v0.3.3: optional local chat persistence and speech lifecycle bridge; v0.3.2: larger conversation panel, in-session history, text composer, keyboard and future voice hooks; v0.3.1: on-demand avatar settings; v0.3.0: four selectable procedural avatar profiles, localized advice and optional XR Hands OK gesture source. Unity/device tests, international font/RTL validation, natural local speech, dictation and reviewed avatar models remain pending.
4. Challenge and hackathon source adapters, browser and document import with provenance.
5. Local AI adapter, mandatory zero-paid-API enforcement, job checkpointing and research evidence review; no commercial providers.
6. Separate patient-service prototype only after privacy, security and clinical governance review.
7. Multiplayer avatar presence and optional video.
8. Author-reviewed logo, five store visuals, English About and Help videos (max 30 seconds each), then nine localized versions of each, narration and subtitles. No publication before approval.
9. Quest build, physical device testing, accessibility and store requirements review.
