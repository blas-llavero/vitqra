# Assistant prototype (v0.3.2)

The avatar panel is hidden by default. Select Avatar settings on the AI Settings panel to open it in that panel's place. Next avatar cycles through Man, Woman, Boy and Girl; Close restores AI Settings. Move the avatar panel with grip. At first use, no profile is selected. Reset closes avatar configuration and restores the default layout. Each selection persists in non-secret preferences. The geometry is generated by original C# at runtime and contains no imported models or media. It is a symbolic bust, not a realistic or animated person.

## Text and task review

Three localized example tips are displayed as text in Smart Advice. On startup, Review tip or Next tip, the sample tip is appended to the larger Conversation panel and it opens in place of Smart Advice. The panel is independent of the avatar, stays visible until minimized and retains session history. See [conversation setup](CONVERSATION_SETUP.md). Press Review tip to arm a single sample review. Press Confirm review to confirm via controller, or use the optional OK gesture. Next tip advances only after confirmation. Confirmation records a local UI state for the current session, not evidence of scientific or medical task completion.

## Optional OK gesture

1. Install a compatible Unity XR Hands package (com.unity.xr.hands) in the Mixed Reality template.
2. Enable Hand Tracking Subsystem and Meta Quest support under Android OpenXR features. Check tracking with the package sample and resolve project validation.
3. In Android Player Settings, add VITQRA_XR_HANDS to Scripting Define Symbols. Do not add it for a build without XR Hands. The source compiles without the optional adapter when the symbol is absent.
4. Enable hand tracking on the headset. Arm Review tip using a controller before switching to hand tracking.
5. Show an open/neutral hand, then touch thumb and index finger while extending the other three fingers for about 0.7 seconds. Either hand can be used; losing tracking or breaking the pose cancels progress. A new review requires a fresh neutral pose.
6. The heuristic is provisional and requires physical calibration. Controller confirmation is always available. Hand-only panel manipulation is not implemented.

References: https://docs.unity.cn/Packages/com.unity.xr.hands@1.4/manual/openxr-features/handtracking.html and https://docs.unity.cn/Packages/com.unity.xr.hands@1.2/manual/hand-data/xr-hand-access-data.html.

## Speech boundary

AdviceChanged exposes localized text and the resolved language to a future speech adapter. Assistant messages are shown in the conversation, independent of avatar visibility. AddAssistantMessage(message) provides a main-thread entry point for future assistant replies. No audio synchronization is implemented. No audio synthesis, microphone capture, dictation, AI conversation or subtitle synchronization is implemented in this release. No external services or paid requests are made. Future TTS/STT integration must use verified open-source engines and appropriately licensed voice models, with explicit microphone activation and no upload of unreviewed media.

## Acceptance checklist (not run)

- Compile with and without VITQRA_XR_HANDS and validate the Android XR project.
- Start with cleared preferences: the avatar is hidden, four main panels appear, and the central view remains open. Open avatar settings, select a profile, close it, and reset. Verify the conversation appears without opening avatar settings, can be moved and minimized, and keeps its history. Test simultaneous conversation and configuration visibility and independent controls.
- Cycle four profiles, restart, confirm persisted selection; check shader inclusion and appearance in an actual Android build.
- Test each language; verify actual font coverage, Arabic RTL and Hindi shaping, wrapping and visual comfort.
- Arm a review; confirm by controller; ensure a gesture outside a pending review does nothing. Test both hands, short pinches, curled fingers, loss of tracking, held gestures before arming, and consecutive reviews; adjust thresholds using physical tests.
- Verify no microphone or camera-image capture, AI calls, or unapproved media.
