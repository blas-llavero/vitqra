# Local mixed reality avatar meeting — v0.7.0 initial

Closed fictional room exercise, not a real call or clinical encounter. Two fixed private room resources from the v0.6.0 policy, each with its own two fictional participants (patient and clinician), Care/Join grants on fixture days 20–29. Researcher/industry/community meeting grants are future work; do not widen care grants to enable them. Joining does not confer record access. User-selectable roles and time are not authentication. No connection to the clinical diary, reports, patient data, AI conversation, native speech engine or network.

Four existing procedural avatar profiles are reused, without models, textures, recorded voice or other media. The editor menu VITQRA > Synthetic Avatar Meeting Preview allows explicit join/leave, profile selection, muted-by-default simulated speech permission, one speaker at a time, three fixed neutral phrases and pretranslated captions in the ten device languages. No actual speech recognition, translation service, synthesis or audio. A five-second caption lifetime uses an explicitly advanced fixture clock, not real elapsed time. Muting, leaving, access expiry or clearing the session removes the active caption when relevant. Only joined authorized participants receive it. No history, recording, free text or persistence. A new session clears prior state. The word muted is a simulation control, never a microphone permission.

Optional 3D display: in an otherwise empty Play-mode scene, use the preview button to create two procedural busts using VitqraAvatarPreview. Inspect in Scene view or place a test camera in the empty scene. It refuses creation when an active VITQRA spatial workspace is found; do not use it in the normal workspace. No changes to saved panel layout, default avatar hiding, scene assets or runtime startup. Editor window captions are not world-space subtitles. No headset deployment or pose transmission. Core labels and neutral phrases translated, technical menu labels remain English. These are authored phrases, not validated live multilingual translation.

JavaScript reference reproduction: 22 assertions. C# checks supplied, not compiled/run in Unity. Three-dimensional display and platform support untested. No new dependencies. No live identity, audio, encryption or real-time room security claim. Next v0.7.1: controlled pose/telepresence simulation, followed by reviewed opt-in transport architecture, secure signaling, authenticated per-room authorization, media consent, microphone controls, encrypted transport, revocation, accessibility and device tests. Actual patient/industry meetings remain blocked until governance and security are established. Never transmit patient data via the existing AI assistant or ordinary research exports.
